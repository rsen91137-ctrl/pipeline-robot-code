# 电机实际转速的一维卡尔曼滤波

本次仅新增 `alg_kalman.h`、`alg_kalman.c` 和本说明。原有源码、PID 参数、CAN/UART 协议、Keil 工程配置均不修改。因此滤波函数目前不会自动运行，需要你决定接入位置后手动调用。

## 1. 文件和接口

- `alg_kalman.h`：状态结构体、状态码和函数声明；兼容 C/C++。
- `alg_kalman.c`：滤波实现；无 HAL/CMSIS 依赖、无动态内存、无全局共享滤波状态。
- 一个电机用一个 `Kalman1D` 实例，四个电机必须分别创建实例。

```c
Kalman1D_Status Kalman1D_Init(Kalman1D *filter, float q, float r, float p0);
Kalman1D_Status Kalman1D_Update(Kalman1D *filter, float raw,
                              float dt_seconds, float *filtered);
Kalman1D_Status Kalman1D_SetNoise(Kalman1D *filter, float q, float r);
Kalman1D_Status Kalman1D_Reset(Kalman1D *filter);
```

`Init` 必须在首次使用前成功执行。`KALMAN1D_INITIALIZER` 只用于清零结构体，不能代替 `Init`。

## 2. 与当前工程的对应关系

你的工程 `MDK-ARM/test_feedback.uvprojx` 使用 ARM Compiler 5.06 update 7，配置中还含有全局 `--cpp11`，并包含 `..\User` 头文件搜索路径。本模块分别按 C99 和工程所用 C++11 模式验证。将 `User/alg_kalman.c` 在 Keil 中通过 **Add Existing Files to Group** 加入编译即可，`.h` 无需单独编译。本次没有替你改 `.uvprojx`。

`User/dvc_motor.cpp` 中，新 CAN 样本被解码后得到 `Now_Omega`：

| 电机 | 类 | 速度变量单位 |
|---|---|---|
| GM6020 / motor2 | `Class_Motor_GM6020` | 电机轴 rad/s |
| M2006 / motor3、motor4 | `Class_Motor_C610` | 已按该类 `Gearbox_Rate` 换算的 rad/s |
| M3508 / motor | `Class_Motor_C620` | 已按该类 `Gearbox_Rate` 换算的 rad/s |

建议先保留原始 `Now_Omega`，另外存一份滤波结果用于对比绘图。确认响应延迟可接受后，再决定是否送入速度 PID。将滤波放入 PID 反馈会引入相位滞后，原先参数可能需要重新验证。

**只在每路新反馈到达时更新一次。** 不要放到 `Get_Now_Omega()`、绘图函数、每次主循环读取的位置或 SysTick 累计路程函数中：这些位置可能多次读到同一个 CAN 样本，重复滤波会错误地提高对旧数据的信任。

不要对目标转速、停机指令或用于行进安全检查的原始速度做同样的平滑。该模块只处理你主动传入的实际速度，不会自行修改任何变量或控制指令。

## 3. 最小调用示例（示例未写入现有源码）

```c
#include "alg_kalman.h"

static Kalman1D gm6020_speed_filter = KALMAN1D_INITIALIZER;
static float gm6020_filtered_omega;

/* 上电时调用一次。以下参数只是调用演示，需用实际数据调整。 */
static Kalman1D_Status Init_GM6020_Speed_Filter(void)
{
    return Kalman1D_Init(&gm6020_speed_filter, 1.0f, 0.04f, 0.04f);
}

/* 仅在拿到一条新的 GM6020 速度反馈后调用。
 * raw_omega_rad_s：已正确解码的原始 rad/s。
 * sample_dt_seconds：该路反馈相邻两次成功更新之间的真实间隔（秒）。
 */
static Kalman1D_Status Update_GM6020_Speed_Filter(float raw_omega_rad_s,
                                               float sample_dt_seconds)
{
    float candidate;
    Kalman1D_Status status;
    status = Kalman1D_Update(&gm6020_speed_filter, raw_omega_rad_s,
                             sample_dt_seconds, &candidate);
    if (status >= 0)
    {
        gm6020_filtered_omega = candidate;
    }
    return status;
}
```

调用者应检查 `Init` 返回值。返回 `KALMAN1D_OK` 才表示初始化成功。首个有效反馈返回 `KALMAN1D_FIRST_SAMPLE`，输出等于原始反馈，不会从零慢慢爬升。其他成功更新返回 `KALMAN1D_OK`。

`dt_seconds` 必须大于零。例如 **1 ms 写 `0.001f`，不是 `1.0f`**。第一帧尚无历史时间，可用已知名义采样周期播种；之后使用各路实际采样间隔。

若用计时器计算间隔，建议采用分辨率足够的微秒计时器，并正确处理无符号回绕。CAN 反馈可能在同一毫秒内到达，单用 `HAL_GetTick()` 相减容易得到零；不能因此重复处理旧帧或把 `dt` 随意当成 1 秒。每路电机单独记录时间。失败或跳过的样本不更新时间基准，下次使用距上次成功更新的总间隔。长时间断连后，建议 `Reset` 再接收新反馈，避免沿用失效历史。

## 4. 参数含义与调节

模型为“实际速度在相邻样本间随机变化，测量值等于速度加噪声”，没有使用电机转矩模型，也没有把设定速度当成实际速度。

```text
x_prior = x
P_prior = P + q * dt
K       = P_prior / (P_prior + r)
x_new   = (1-K) * x_prior + K * measurement
P_new   = (1-K)^2 * P_prior + K^2 * r
```

- `q`：每秒过程噪声方差，单位 `(速度单位)^2/s`，不是标准差，也不是简单的“加速度”。取值越大通常跟随越快、平滑越弱。一般电机变速场景用 `q > 0`。
- `r`：速度测量噪声方差，单位 `(速度单位)^2`。可在稳定转速下采集原始反馈，估算去除均值后的样本方差。反馈量化、负载引起的真实波动和通信损坏需要区分。
- `p0`：首帧播种后的初始估计方差。没有其他先验信息时，可先设置为 `r`。
- `q >= 0`；`r` 和 `p0` 至少为 `FLT_MIN`。所有参数都必须有限。

同一组数值不能直接混用 rpm、rad/s、m/s。如果速度单位乘以 `c`，则 `q`、`r`、`p0` 都要乘以 `c*c`。例如从 rpm 改为 rad/s，`c = 2*pi/60`。

先用静止、稳定正转、稳定反转和速度阶跃四组数据比对原始/滤波曲线。滤波强度和响应延迟需要一起检查，不能只看曲线是否平滑。`q = 0` 表示理想恒定状态，长时间运行后会越来越不愿跟随变速，一般不适合作为电机动态速度的默认设置。

`SetNoise` 改变 `q/r` 并保留当前状态；修改 `p0` 可重新 `Init`。`Reset` 保留噪声参数，清除历史，等待下一帧重新播种。不要每帧重新初始化，否则实际上没有连续滤波。

## 5. 异常、精度和执行开销

- NaN、正负无穷、非法采样间隔、空指针、未初始化状态和数值溢出都返回负状态码；滤波状态及输出参数保持原样。失败不能当作“速度为零”。
- 有限的速度突变不会被静默丢弃。本模块没有异常点门限，不会把正反转或真实加减速直接当噪声删除。若存在串口/CAN 解码错误，应先修复数据源。
- 协方差采用 Joseph 形式，局部运算使用 `double` 防止极端合法 `float` 输入在中间计算时溢出；外部数据和持久状态仍为 `float`。协方差最低保留 `FLT_MIN`，避免浮点下溢后冻结。
- STM32F427 仅有单精度硬件 FPU，局部双精度运算会由软件辅助完成。本次已验证能编译，但没有测量板上耗时。放入高频中断前需测量执行时间，必要时把新样本送入单一处理任务。
- 同一实例不允许由主循环和中断同时更新；跨上下文发布原始速度、滤波速度、时间戳等组合数据时，应由调用方保证一致性。
- 不启用 `-ffast-math` 等假设不存在 NaN/Inf 的优化；它们可能使异常检查失效。

状态码详见 `alg_kalman.h`。输出指针必须指向独立的 `float`，不要指向滤波状态结构体的字段。

## 6. 数学参考

基础离散预测/测量更新可参考 [MathWorks：Kalman Filtering](https://www.mathworks.com/help/control/ug/kalman-filtering.html)。本模块在此基础上取标量状态、`F=H=1`，并用 `q*dt` 表示每个采样间隔的过程方差。

模块用于反馈平滑，不能据此判定或修复此前 GM6020 堵转的根因。
